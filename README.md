# 2 года без сигарет

Домашнее приложение для iPhone и iPad: сундучок на каждый из 730 дней, вехи здоровья, награды, копилка и журнал тяги. Работает без интернета, все данные хранятся только на устройстве.

## Как опубликовать (один раз)

1. Распакуй архив: в приложении «Файлы» коснись ZIP — рядом появится папка с файлами.
2. На github.com войди в аккаунт и создай репозиторий: «+» → New repository. Имя латиницей, например `quit2y`. Видимость — **Public** (на бесплатном тарифе GitHub Pages работает только для публичных репозиториев; код виден всем, твои данные — нет).
3. В репозитории: Add file → Upload files → выбери **все файлы из папки** (не саму папку) → Commit changes.
4. Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
5. Через 1–2 минуты вверху страницы Pages появится адрес вида `https://имя.github.io/quit2y/`.

## Как установить на iPhone

1. Открой адрес **в Safari** → «Поделиться» → «На экран „Домой“» → «Добавить».
2. Запускай с иконки «Не курю» и только после этого вводи данные: у установленного приложения своё хранилище, отдельное от вкладки Safari.

## Резервная копия

Настройки → «Сохранить копию» → «Сохранить в Файлы». Если удалить иконку, данные пропадут — копия их вернёт («Восстановить из копии»). Этим же файлом можно перенести данные с iPhone на iPad.

## Обновление

1. Загрузи изменённые файлы поверх старых: Add file → Upload files → Commit changes.
2. Открой приложение с иконки — появится «Доступна новая версия» → «Обновить». Если баннера нет, закрой приложение смахиванием и открой снова.

## Режим отладки

Настройки → 7 раз коснись строки с номером версии. Можно сдвигать «сегодня» вперёд, создать демо-данные за 60 дней и проверить раскладку наград. Перед этим сделай резервную копию: демо-данные заменяют настоящие.
